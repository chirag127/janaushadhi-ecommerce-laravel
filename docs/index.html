Jan Aushadhi Ecommerce

A self-hostable storefront for affordable generic medicines — Laravel 12, Livewire, Tailwind.

View on GitHub Deploy it

What it is

A complete ecommerce platform for selling generic (unbranded) medicines — the kind sold under India's Jan Aushadhi scheme at a fraction of branded-drug prices. It gives a pharmacy a full online store: browsable catalog, cart, Razorpay + cash-on-delivery checkout, customer accounts, and an admin back office for products, inventory, orders, coupons, and reports.

It is a self-hostable application, not a hosted service. Clone it, point it at a PostgreSQL database, and run your own store.

Features

  • Storefront: catalog, search, category filtering, product pages, reviews
  • Livewire cart & wishlist with live counters
  • Checkout via Razorpay or cash-on-delivery, with coupons and configurable shipping
  • Customer accounts, saved addresses, order history, social login (Google/GitHub/Microsoft/Facebook)
  • Admin portal with RBAC: products, inventory, orders, coupons, customers, reports

Deploy

git clone https://github.com/chirag127/janaushadhi-ecommerce-laravel.git
cd janaushadhi-ecommerce-laravel
composer install && npm install
cp .env.example .env && php artisan key:generate
php artisan migrate --seed
composer dev   # server + queue + vite

Docker and Render blueprints are included — see the README and docs/deploy-render.md.
